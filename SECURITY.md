# Security Policy

## Supported versions

This is a portfolio demo; only the `main` branch receives fixes.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Instead, use GitHub's private vulnerability reporting:

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Provide a clear description, steps to reproduce, and any suggested
   mitigation.

You should expect an acknowledgement within five business days. Once a
fix lands on `main`, the advisory will be published.
